Enterprise Privacy & Architecture

LocalLog is engineered from the ground up for strict enterprise environments where data privacy, zero telemetry, and security transparency are paramount:

  • Zero Network Traffic: The application runs 100% client-side inside your browser sandbox. It makes zero outbound network calls, transmits no telemetry, and uses no external cloud databases.
  • Offline-First Service Worker: Once cached, the app functions completely offline without an internet connection.
  • Local Persistence: All project titles, hourly rates, and time entries reside exclusively inside your computer's browser IndexedDB and optional local CSV folder.
  • Transparent & Auditable: Built using zero-build pure web standards (HTML5/CSS/JavaScript). Internal security and IT teams can inspect every line of source code.
